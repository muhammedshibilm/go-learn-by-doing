# Lesson 01: Hello World

## Goal
Make the function `Hello` return the text `Hello, World!`.

## Steps
1. Open `main.go`.
2. Find the `TODO` and fix the `Hello` function.
3. Run the test:
```bash
   go test ./lessons/1-beginner/01-hello-world/
```
4. When the test passes, commit and push:
```bash
   git add .
   git commit -m "finish lesson 01"
   git push
```

## Hint
A string in Go is written inside double quotes: `"like this"`.
A function sends a value back with the `return` keyword.
